# IA-007: Búsqueda BM25, búsqueda híbrida y comando `buscar`

## Contexto

**BM25** es búsqueda clásica por palabras: acierta en consultas literales
("artículo 47", "convalidación") justo donde la búsqueda por embeddings suele
fallar, y no necesita IA. La búsqueda **vectorial** (IA-008) acierta en lo
coloquial. Queremos las dos, pero sus puntajes no son comparables (BM25 no
tiene tope; el coseno va de -1 a 1). *Reciprocal Rank Fusion* (**RRF**) las
combina usando solo la **posición** de cada resultado.

Al final, un comando de consola permite comprobar a ojo qué recupera la
búsqueda, en segundos y en las demos.

La Parte 1 (BM25) solo necesita `data/fragmentos.json` (IA-002): **empiézala
en cuanto IA-002 esté cerrada**. Las Partes 2 y 3 necesitan
`ia/vectorial.py` (IA-008).

Esta tarea junta las antiguas IA-007 (BM25), IA-010 (híbrida con RRF) e IA-011
(comando `buscar`).

## Objetivo

Crear `ia/bm25.py`, `ia/hibrida.py` con la función única
`buscar(pregunta, modo="hibrida", k=5)` que el resto del sistema usará siempre,
y `ia/buscar.py` para que `python -m ia.buscar "pregunta" --modo hibrida`
imprima los 5 mejores fragmentos.

## Entradas

- `data/fragmentos.json` (IA-002)
- `ia/vectorial.py` (IA-008), `ia/db.py` (`leer_fragmentos`, BE-008)
- `docs/ARQUITECTURA.md`, sección *Resultado de búsqueda*
- `eval/preguntas.jsonl` (IA-001), para elegir preguntas de prueba

## Pasos

### Parte 1: BM25 (`ia/bm25.py`)

1. Añade `rank-bm25` a `requirements.txt` e instálalo.
2. Escribe `tokenizar(texto: str) -> list[str]`:
   - Pasa a minúsculas.
   - Quita las tildes: `unicodedata.normalize("NFD", texto)` y descarta los
     caracteres cuya `unicodedata.category(c)` sea `"Mn"`.
   - Separa en palabras con `re.findall(r"\w+", texto)`.
3. Escribe `crear_indice_bm25(fragmentos: list[dict])`, que devuelve
   `BM25Okapi([tokenizar(f["texto"]) for f in fragmentos])`.
4. Escribe
   `buscar_bm25(pregunta: str, fragmentos: list[dict], indice, k: int = 5) -> list[dict]`:
   tokeniza la pregunta, calcula `indice.get_scores(tokens)`, ordena de mayor
   a menor y devuelve los `k` primeros como
   `{"id": f["id"], "puntaje": puntaje, "fragmento": f}`.

### Parte 2: búsqueda híbrida (`ia/hibrida.py`)

5. Escribe `fusionar_rrf(listas: list[list[dict]], k: int = 5, K: int = 60) -> list[dict]`:
   - Para cada lista y cada resultado en la posición `p` (empezando en 1),
     suma `1 / (K + p)` al total de su `id`.
   - Ordena los `id` por su total, de mayor a menor, y devuelve los `k`
     mejores con el formato del contrato y ese total como `puntaje`.
6. Escribe `cargar()`: lee los fragmentos de la base con `leer_fragmentos()`,
   crea el índice BM25 y guarda los dos en variables del módulo
   (`_fragmentos` e `_indice`). BE-003 la llamará al arrancar la API.
7. Escribe `buscar(pregunta: str, modo: str = "hibrida", k: int = 5) -> list[dict]`:
   - Si `_fragmentos` todavía es `None`, llama a `cargar()`. Así la segunda
     llamada no vuelve a leer la base.
   - `modo` puede ser `"bm25"`, `"vectorial"` o `"hibrida"`. Con otro valor,
     lanza `ValueError`.
   - Para la híbrida, pide **20** candidatos a cada búsqueda, fusiónalos con
     `fusionar_rrf` y devuelve los `k` mejores.
   - En cada resultado híbrido añade la clave `puntaje_vectorial`: el
     `puntaje` que tuvo ese fragmento en la búsqueda vectorial, o `None` si no
     salió en ella. Lo necesita IA-016 para el umbral de rechazo.

### Parte 3: el comando `buscar` (`ia/buscar.py`)

8. Con `argparse`: argumento posicional `pregunta`, opción `--modo`
   (`choices=["bm25", "vectorial", "hibrida"]`, por defecto `hibrida`) y
   `--k` (entero, por defecto 5).
9. Para cada resultado, imprime: posición, puntaje con 3 decimales, `id`,
   página y los primeros 200 caracteres del texto.

## Fuera de alcance

- Palabras vacías (*stopwords*) y *stemming*: se prueban después solo si una
  medición lo justifica.
- Pesos distintos para cada búsqueda y *rerankers*.
- Generar respuestas (IA-016).

## Criterios de aceptación

- [ ] `buscar_bm25` devuelve exactamente `k` resultados, de mayor a menor
      puntaje, y "Artículo" y "articulo" dan el mismo resultado.
- [ ] Con una pregunta `literal` del golden set, BM25 pone el artículo esperado
      en el top-5.
- [ ] `fusionar_rrf` probado a mano: con `[[A, B], [B, C]]`, B queda primero.
- [ ] `buscar` funciona en los tres modos, devuelve el formato del contrato y
      la segunda llamada no vuelve a leer la base.
- [ ] Los resultados híbridos tienen `puntaje_vectorial`.
- [ ] `python -m ia.buscar` funciona con los tres modos y `--help` explica las
      opciones.

## Cómo verificar

```bash
python -c "
import json
from ia.bm25 import crear_indice_bm25, buscar_bm25
f = json.load(open('data/fragmentos.json', encoding='utf-8'))
i = crear_indice_bm25(f)
for r in buscar_bm25('<pregunta literal del golden set>', f, i):
    print(round(r['puntaje'], 2), r['id'])
"
python -c "
from ia.hibrida import fusionar_rrf
a = {'id': 'A', 'puntaje': 1, 'fragmento': {}}
b = {'id': 'B', 'puntaje': 1, 'fragmento': {}}
c = {'id': 'C', 'puntaje': 1, 'fragmento': {}}
print([r['id'] for r in fusionar_rrf([[a, b], [b, c]])])    # B primero
"
python -m ia.buscar "cuántas faltas puedo tener" --modo bm25
python -m ia.buscar "me pueden echar por faltar mucho"
python -m ia.buscar --help
```
