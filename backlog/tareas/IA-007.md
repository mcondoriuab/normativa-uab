# IA-007: Búsqueda BM25

## Contexto

BM25 es búsqueda clásica por palabras. Acierta en consultas literales
("artículo 47", "convalidación") justo donde la búsqueda por embeddings suele
fallar. Es la primera búsqueda del sistema y no necesita IA.

## Objetivo

Crear `ia/bm25.py` con `crear_indice_bm25(fragmentos)` y
`buscar_bm25(pregunta, fragmentos, indice, k=5)`, que devuelve resultados con el
formato del contrato.

## Entradas

- `data/fragmentos.json`
- `docs/ARQUITECTURA.md` (sección *Resultado de búsqueda*)

## Pasos sugeridos

1. Añade `rank-bm25` a `requirements.txt`.
2. Escribe `tokenizar(texto)`: minúsculas, quitar tildes (con
   `unicodedata.normalize("NFD", ...)` y descartar los caracteres de la
   categoría `Mn`) y separar por lo que no sea letra o número (`re.findall(r"\w+", ...)`).
3. `crear_indice_bm25`: `BM25Okapi([tokenizar(f["texto"]) for f in fragmentos])`.
4. `buscar_bm25`: tokeniza la pregunta, `indice.get_scores(...)`, ordena de mayor
   a menor y devuelve los `k` primeros como `{"id", "puntaje", "fragmento"}`.

## Fuera de alcance

- Palabras vacías (stopwords), *stemming*: se prueban después solo si una
  medición lo justifica.

## Criterios de aceptación

- [ ] Devuelve exactamente `k` resultados, ordenados de mayor a menor puntaje.
- [ ] "Artículo" y "articulo" dan el mismo resultado.
- [ ] Con una pregunta literal del golden set, el artículo esperado sale en el
      top-5.

## Cómo verificar

```bash
python -c "
import json
from ia.bm25 import crear_indice_bm25, buscar_bm25
f = json.load(open('data/fragmentos.json', encoding='utf-8'))
i = crear_indice_bm25(f)
for r in buscar_bm25('<pregunta literal del golden set>', f, i):
    print(round(r['puntaje'], 2), r['id'])
"
```
