# IA-005: Comando ingestar

## Contexto

Unimos extracción y troceado en un comando que procesa la carpeta de una
carrera y guarda todos los fragmentos en un solo archivo. Es lo que se vuelve a
ejecutar cada vez que cambia la normativa.

## Objetivo

Crear `ia/ingestar.py` para que
`python -m ia.ingestar corpus/ingenieria-sistemas` genere `data/fragmentos.json`
e imprima estadísticas.

## Entradas

- `ia/extraer.py`, `ia/trocear.py`
- `docs/ARQUITECTURA.md`

## Pasos sugeridos

1. Recibe la carpeta con `sys.argv` o `argparse`.
2. Para cada `*.pdf` (en orden alfabético): `documento` = nombre sin extensión,
   extrae las páginas y trocéalas.
3. Crea `data/` si no existe y guarda la lista con
   `json.dump(..., ensure_ascii=False, indent=2)`.
4. Imprime por documento: páginas, fragmentos, cuántos con artículo, y un aviso
   si todas las páginas salieron vacías (probable escaneado).
5. Imprime el total al final.

## Fuera de alcance

- Embeddings (IA-008).

## Criterios de aceptación

- [ ] Genera `data/fragmentos.json` válido y conforme al contrato.
- [ ] Los `id` son únicos en todo el archivo.
- [ ] Se ve el resumen por documento y el total.
- [ ] `data/` no aparece en `git status`.

## Cómo verificar

```bash
python -m ia.ingestar corpus/ingenieria-sistemas
python -c "
import json; f = json.load(open('data/fragmentos.json', encoding='utf-8'))
ids = [x['id'] for x in f]; print(len(f), 'fragmentos,', len(set(ids)), 'ids únicos')
"
```

## Entregables

- `ia/ingestar.py`

## Para aprender

Pipelines de datos reproducibles; por qué los datos generados no se versionan.
