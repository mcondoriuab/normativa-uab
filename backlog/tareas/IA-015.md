# IA-015: Prompt del sistema v1

## Contexto

El prompt del sistema son las reglas que el modelo recibe siempre. Aquí se
decide si cita, si rechaza cuando no sabe y si se inventa cosas. Es código:
se versiona y cada cambio se prueba.

## Objetivo

Crear `ia/prompts.py` con la constante `SISTEMA` y documentar cada regla y su
porqué.

## Entradas

- `docs/ARQUITECTURA.md` (principios; formato `[n]` de las citas)
- `docs/ETICA.md`
- `investigacion/INV-001-que-es-un-llm.md`

## Pasos sugeridos

1. Escribe el prompt en español. Debe imponer al menos estas reglas:
   1. Responder **solo** con los fragmentos recibidos, sin conocimiento propio.
   2. Poner `[n]` después de cada afirmación, donde `n` es el número del
      fragmento.
   3. Si la respuesta no está en los fragmentos, contestar exactamente con una
      frase de rechazo fija (defínela como constante `FRASE_RECHAZO`).
   4. Si dos fragmentos se contradicen, decirlo en vez de elegir uno.
   5. No opinar sobre casos personales ni predecir decisiones de la
      universidad.
   6. Respuestas breves y en español claro, sin cambiar el sentido del texto
      normativo.
2. Prueba el prompt con `ia.llm.generar` y 3 preguntas, pegando a mano 5
   fragmentos numerados: una que se pueda responder, una que no y una con
   caso personal.
3. Crea `docs/PROMPTS.md` con la versión (v1), el texto, el porqué de cada regla
   y el resultado de las 3 pruebas.

## Fuera de alcance

- Armar el contexto automáticamente (IA-016).

## Criterios de aceptación

- [ ] `SISTEMA` y `FRASE_RECHAZO` existen en `ia/prompts.py`.
- [ ] Las 6 reglas están en el prompt.
- [ ] `docs/PROMPTS.md` documenta la v1 y las 3 pruebas con las salidas reales.

## Cómo verificar

```bash
python -c "from ia.prompts import SISTEMA, FRASE_RECHAZO; print(SISTEMA); print(FRASE_RECHAZO)"
```
