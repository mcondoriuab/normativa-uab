# IA-016: Función responder() con citas

## Contexto

Es la pieza que une todo: busca, arma el contexto con fragmentos numerados,
llama al modelo y devuelve la respuesta con la forma exacta que espera la API.

## Objetivo

Crear `ia/responder.py` con `responder(pregunta: str) -> dict`, que devuelve un
diccionario con el formato de la respuesta de `POST /preguntar`.

## Entradas

- `ia/hibrida.py` (`buscar`), `ia/llm.py` (`generar`),
  `ia/prompts.py` (`SISTEMA`, `FRASE_RECHAZO`)
- `docs/ARQUITECTURA.md` (sección *API*)

## Pasos sugeridos

1. `resultados = buscar(pregunta, k=5)` con el modo decidido en IA-013.
2. Arma el mensaje: cada fragmento como `[n] documento, Art. X, pág. Y:\n<texto>`,
   y al final la pregunta.
3. `texto = generar(SISTEMA, mensaje)`.
4. Si el texto contiene `FRASE_RECHAZO`, devuelve `rechazada: True` y
   `citas: []`.
5. Si no, las citas son los fragmentos cuyos `[n]` aparecen en el texto
   (búscalos con una regex `\[(\d+)\]`), conservando su número `n`.
6. Añade siempre el campo `aviso` del contrato.
7. Bloque `__main__` para probarlo por consola.

## Fuera de alcance

- Umbral de relevancia (IA-017).

## Criterios de aceptación

- [ ] El diccionario tiene exactamente los campos del contrato.
- [ ] Cada `[n]` del texto tiene su cita con el mismo `n`, y no hay citas que
      no se mencionen.
- [ ] Una pregunta fuera de corpus del golden set devuelve `rechazada: True`
      (si no, anótalo: lo arregla IA-017).

## Cómo verificar

```bash
python -m ia.responder "cuántas faltas puedo tener"
python -m ia.responder "quién ganó el mundial de 2022"
```
