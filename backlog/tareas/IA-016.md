# IA-016: `responder()` con citas y umbral de rechazo calibrado

## Contexto

Es la pieza que une todo: busca, arma el contexto con fragmentos numerados,
llama al modelo y devuelve la respuesta con la forma exacta que espera la API.

Pedirle al modelo que rechace no basta: si le pasamos fragmentos poco
relevantes, a veces igual "responde". Por eso hay una defensa más: si el mejor
fragmento se parece poco a la pregunta, se rechaza **sin llamar al modelo**, lo
que además ahorra cuota gratuita. El umbral no se inventa: se calibra con el
golden set.

Es una tarea del **camino crítico**: BE-003 la conecta a la API el 16 de
noviembre. Puedes escribir los pasos 2 a 6 en cuanto INV-010 esté cerrada,
antes de que exista `buscar()`.

Esta tarea junta las antiguas IA-016 (`responder()` con citas) e IA-017
(umbral de rechazo calibrado).

## Objetivo

Crear `ia/responder.py` con `responder(pregunta: str) -> dict`, que devuelve un
diccionario con el formato exacto de la respuesta de `POST /preguntar`, y que
rechaza sin llamar al LLM cuando el mejor fragmento no supera un
`UMBRAL_RELEVANCIA` calibrado con el golden set.

## Entradas

- `ia/hibrida.py`, función `buscar` y su campo `puntaje_vectorial` (IA-007)
- `ia/llm.py` (`generar`) e `ia/prompts.py` (`SISTEMA`, `FRASE_RECHAZO`)
  (INV-010)
- `eval/preguntas.jsonl` (IA-001)
- `docs/ARQUITECTURA.md`, sección *API* (forma de la respuesta y de cada cita)
- `historial/evaluaciones/_plantilla.md`

## Pasos

### Parte 1: `responder()`

1. Al principio de `ia/responder.py`, define estas constantes:

   ```python
   MODO_BUSQUEDA = "hibrida"      # lo confirma o lo cambia el ADR de IA-012
   UMBRAL_RELEVANCIA = 0.0        # se calibra en la Parte 2
   AVISO = "Herramienta de apoyo. El texto oficial y vinculante es el publicado por la universidad."
   ```

2. Escribe `armar_mensaje(pregunta: str, resultados: list[dict]) -> str`: cada
   fragmento numerado desde 1 con el formato
   `[n] documento, Art. X, pág. Y:\n<texto>` (si `articulo` es `None`, quita
   `Art. X, `), separados por una línea en blanco, y al final
   `Pregunta: <pregunta>`.
3. Escribe `extraer_citas(texto: str, resultados: list[dict]) -> list[dict]`:
   busca los `[n]` del texto con `re.findall(r"\[(\d+)\]", texto)` y, para
   cada `n` distinto (en orden de aparición, sin repetir), arma
   `{"n": n, "documento", "articulo", "pagina", "texto"}` con los datos de
   `resultados[n - 1]["fragmento"]`. Ignora los `n` que no existan en
   `resultados`.
4. Escribe `respuesta_rechazo() -> dict`, que devuelve
   `{"respuesta": FRASE_RECHAZO, "rechazada": True, "citas": [], "aviso": AVISO}`.
5. Escribe `responder(pregunta: str) -> dict`:
   1. `resultados = buscar(pregunta, modo=MODO_BUSQUEDA, k=5)`.
   2. Calcula el **mayor** `puntaje_vectorial` entre los resultados,
      ignorando los `None` (un resultado puede venir solo de BM25). Si no hay
      ninguno, o es menor que `UMBRAL_RELEVANCIA`, devuelve
      `respuesta_rechazo()` **sin llamar a `generar`**.
   3. `texto = generar(SISTEMA, armar_mensaje(pregunta, resultados))`.
   4. Si `FRASE_RECHAZO` está en `texto`, devuelve `respuesta_rechazo()`.
   5. Si no, devuelve
      `{"respuesta": texto, "rechazada": False, "citas": extraer_citas(texto, resultados), "aviso": AVISO}`.
6. Añade un bloque `if __name__ == "__main__":` que lea la pregunta de
   `sys.argv[1]` e imprima el resultado con
   `json.dumps(..., ensure_ascii=False, indent=2)`.

### Parte 2: calibrar el umbral

7. Crea `eval/umbral.py`: para cada pregunta del golden set, llama a
   `buscar(pregunta, modo=MODO_BUSQUEDA, k=5)` y guarda el mayor
   `puntaje_vectorial` de los resultados (el mismo cálculo del paso 5.2) junto
   a `en_corpus`. **No llames al LLM** aquí.
8. Imprime los puntajes de las preguntas en corpus y los de fuera de corpus,
   ordenados. Después, para estos umbrales candidatos: 0.3, 0.35, 0.4, 0.45,
   0.5, 0.55 y 0.6, imprime cuántas de cada grupo se rechazarían. Si los
   puntajes de tu modelo están en otra escala, elige candidatos entre el menor
   y el mayor puntaje que salieron.
9. Elige el umbral que rechaza todas (o casi todas) las de fuera de corpus
   rechazando el mínimo de las legítimas, y ponlo en `UMBRAL_RELEVANCIA` con un
   comentario que enlace la evaluación del paso 10.
10. Registra la calibración en
    `historial/evaluaciones/AAAA-MM-DD-umbral.md` (con la plantilla): la tabla
    de umbrales, el valor elegido y por qué ese compromiso.

## Fuera de alcance

## Criterios de aceptación

- [ ] El diccionario tiene exactamente los campos del contrato:
      `respuesta`, `rechazada`, `citas` y `aviso`.
- [ ] Cada `[n]` del texto tiene su cita con el mismo `n`, y no hay citas que
      no se mencionen.
- [ ] `eval/umbral.py` imprime la tabla de umbrales candidatos.
- [ ] `UMBRAL_RELEVANCIA` tiene un comentario que enlaza la evaluación, y la
      evaluación incluye la tabla y el porqué del valor.
- [ ] Las preguntas fuera de corpus del golden set se rechazan (anota en
      *Notas de cierre* cuántas se rechazan sin llamar al LLM).

## Cómo verificar

```bash
python -m eval.umbral
python -m ia.responder "cuántas faltas puedo tener"
python -m ia.responder "quién ganó el mundial de 2022"         # rechazada: true
python -m ia.responder "cuál es la mejor universidad del país" # rechazada: true
```
