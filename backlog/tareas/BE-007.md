# BE-007: Despliegue del MVP completo

## Contexto

La API ya se despliega sola desde BE-006, pero solo con `/salud`. Ahora hay que
dejar en producción el sistema completo: web, búsqueda sobre Supabase, LLM y
registro de consultas, con sus secretos configurados en Render.

## Objetivo

Que la URL pública responda preguntas reales con citas, igual que en local.

## Entradas

- `render.yaml`, `docs/DESPLIEGUE.md`, `.env.ejemplo`
- `db/README.md` (migraciones aplicadas)

## Pasos sugeridos

1. Comprueba en `db/README.md` que todas las migraciones están aplicadas en
   Supabase y que la tabla `fragmentos` tiene embeddings (IA-008).
2. Declara en `render.yaml` las variables de `.env.ejemplo` con `sync: false`
   (así Render las pide en el panel y **no** se guardan en el repo).
3. El docente rellena los valores en Render (*Environment*), usando la cadena
   **Session pooler** de Supabase para `DATABASE_URL`.
4. Despliega y prueba desde un móvil con datos móviles, no con el wifi de casa:
   una pregunta literal, una coloquial y una fuera de corpus.
5. Comprueba en Supabase que las consultas se registraron en `consultas`.
6. Completa `docs/DESPLIEGUE.md` con lo que haya que saber para repetirlo y
   registra el despliegue.

## Fuera de alcance

- Dominio propio, entornos separados de desarrollo y producción.

## Criterios de aceptación

- [ ] La URL pública responde una pregunta del golden set con citas reales.
- [ ] Una pregunta fuera de corpus se rechaza.
- [ ] Ningún secreto aparece en `render.yaml` ni en git.
- [ ] Las consultas de prueba aparecen en la tabla `consultas`.
- [ ] `docs/DESPLIEGUE.md` permite a otra persona repetir el despliegue.

## Cómo verificar

```bash
curl -s -X POST https://<servicio>.onrender.com/preguntar \
     -H 'Content-Type: application/json' -d '{"pregunta": "<pregunta del golden set>"}'
git grep -n -i -e "postgresql://" -e "api_key" -- render.yaml     # no debe mostrar valores
```

## Entregables

- `render.yaml`
- `docs/DESPLIEGUE.md`

## Para aprender

Secretos en producción, diferencias entre local y producción, pruebas de humo.
