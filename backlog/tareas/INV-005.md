# INV-005: Reunir y registrar los PDF

## Contexto

Con el inventario de INV-004 hecho, hay que tener los archivos en local para
procesarlos. Los PDF no se suben a git (ver `corpus/README.md`), así que el
registro en `docs/CORPUS.md` es lo que permite a cualquiera reconstruir el
corpus.

## Objetivo

Tener en `corpus/ingenieria-sistemas/` todos los PDF públicos del inventario,
con nombres normalizados y registrados.

## Entradas

- `docs/CORPUS.md` (inventario)
- `corpus/README.md` (convención de nombres)

## Pasos sugeridos

1. Descarga cada PDF público del inventario.
2. Renómbralo: minúsculas, guiones, sin tildes ni espacios
   (`Reglamento Estudiantil 2023.pdf` → `reglamento-estudiantil-2023.pdf`).
3. Cópialo en `corpus/ingenieria-sistemas/`.
4. En `docs/CORPUS.md`, pon el nombre de archivo final en la primera columna.
5. Comparte la carpeta con el equipo por Drive (no por git).

## Fuera de alcance

- Abrir o analizar el contenido (INV-006).
- Documentos no públicos.

## Criterios de aceptación

- [ ] Cada PDF de la carpeta tiene su fila en `docs/CORPUS.md`, y al revés.
- [ ] Todos los nombres siguen la convención.
- [ ] `git status` no muestra ningún PDF.

## Cómo verificar

```bash
ls corpus/ingenieria-sistemas/*.pdf
git status --short | grep -i pdf     # no debe mostrar nada
```

## Entregables

- `docs/CORPUS.md`
- PDFs en `corpus/ingenieria-sistemas/` (solo en local y en Drive)

## Para aprender

Procedencia de datos (*data provenance*) y reproducibilidad.
