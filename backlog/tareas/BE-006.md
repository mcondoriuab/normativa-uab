# BE-006: Primer despliegue en Render

## Contexto

**Tarea de configuración: la hace el docente**, porque usa su cuenta de Render.
Los estudiantes pueden mirar y preguntar en el PR.

Desplegamos **desde el principio**, con la API mínima, para descubrir pronto
los problemas de despliegue en vez de encontrarlos todos juntos la semana de la
demo. La plataforma ya está decidida (ADR-002): Render, plan gratuito, con
despliegue automático en cada merge a `main`. La configuración vive en el repo
como un *Blueprint* (`render.yaml`).

Requisito previo: pasos 1 y 2 de `docs/DESPLIEGUE.md` hechos (repositorio en
GitHub y cuenta de Render).

## Objetivo

Que `https://<servicio>.onrender.com/salud` responda `{"estado": "ok"}` y que
cada merge a `main` redespliegue solo.

## Entradas

- `apps/api/main.py`, `requirements.txt` (BE-001)
- `docs/DESPLIEGUE.md`, ADR-002
- Documentación oficial de Render sobre Blueprints (`render.yaml`) y Python

## Pasos

1. Crea `render.yaml` en la raíz con un solo servicio `web`: runtime Python,
   plan `free`, `buildCommand: pip install -r requirements.txt`,
   `startCommand: uvicorn apps.api.main:app --host 0.0.0.0 --port $PORT` y
   `healthCheckPath: /salud`. Verifica cada clave en la referencia oficial de
   `render.yaml`.
2. Fija la versión de Python como indique la documentación de Render (por
   ejemplo, con la variable `PYTHON_VERSION`).
3. Abre el PR y haz el merge. Crea el Blueprint en Render apuntando al
   repositorio (desde el panel o con el conector de Render).
4. Comprueba la URL y revisa los logs del primer deploy.
5. Pon la URL en `README.md` y registra el despliegue en la tabla de
   `docs/DESPLIEGUE.md`.
6. Avisa en el issue con la URL: BE-008 la necesita para el flujo que mantiene
   activa la base.

## Fuera de alcance

- Base de datos y variables secretas (BE-007).
- Dominio propio.

## Criterios de aceptación

- [x] `render.yaml` existe y no contiene ningún secreto.
- [x] La URL pública responde `/salud`.
- [x] Un cambio mínimo mergeado a `main` se despliega solo (compruébalo en los
      logs de Render).
- [x] URL en el `README.md` y fila en el registro de `docs/DESPLIEGUE.md`.

## Cómo verificar

```bash
curl -s https://normativa-uab-ldxj.onrender.com/salud
```

## Entregables

- `render.yaml`
- `README.md`, `docs/DESPLIEGUE.md`

## Para aprender

Despliegue continuo, infraestructura como código y arranque en frío (llama a la
URL después de 20 minutos sin uso y mide cuánto tarda).

## Notas de cierre

Hecha el 2026-11-09 (PR #68, #69 y #70), antes que BE-001: se desplegó un
`apps/api/hola.py` provisional para no esperar. BE-001 (#72) lo retiró y apuntó
`render.yaml` a `apps.api.main:app`.
