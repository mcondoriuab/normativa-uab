# FE-004: Citas desplegables

## Contexto

La cita textual es lo que hace verificable cada respuesta, pero varios artículos
completos ocupan mucho, sobre todo en el móvil. Cada cita debe mostrar una
cabecera corta y desplegar el texto completo al tocarla.

## Objetivo

Mostrar cada cita como un elemento desplegable con cabecera
`[n] documento · Art. X · pág. Y` y el texto completo dentro.

## Entradas

- `apps/web/app.js`, `apps/web/estilos.css`
- `docs/ARQUITECTURA.md` (campos de `citas`)

## Pasos sugeridos

1. Usa `<details>` y `<summary>`: no necesitan JavaScript para abrir y cerrar.
2. Si `articulo` es `null`, la cabecera no muestra "Art.".
3. Muestra el texto de la cita respetando los saltos de línea
   (`white-space: pre-line`).

## Fuera de alcance

- Resaltar dentro de la respuesta el `[n]` que corresponde a cada cita.

## Criterios de aceptación

- [ ] Las citas empiezan cerradas y se abren y cierran con clic o teclado.
- [ ] La cabecera sigue el formato indicado.
- [ ] Sin `innerHTML`.

## Cómo verificar

Preguntar en `http://localhost:8000/` y abrir y cerrar las citas con el ratón y
con la tecla Enter.

## Entregables

- `apps/web/app.js`
- `apps/web/estilos.css`

## Para aprender

Elementos HTML nativos antes que JavaScript propio.
