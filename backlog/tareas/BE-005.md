# BE-005: Servir la web desde la API

## Contexto

Si la web se abre con doble clic (`file://`) y llama a `localhost:8000`, el
navegador bloquea la petición por CORS. La solución más simple: que la propia
API sirva los archivos de `apps/web/`. Así web y API tienen el mismo origen y no
hace falta configurar CORS.

## Objetivo

Que `http://localhost:8000/` muestre `apps/web/index.html` con su CSS y su JS,
sin romper `/salud` ni `/preguntar`.

## Entradas

- `apps/api/main.py`
- `apps/web/`

## Pasos sugeridos

1. Usa `fastapi.staticfiles.StaticFiles` montado en `/` con `html=True`,
   apuntando a `apps/web`.
2. **El montaje va después de declarar las rutas de la API**; si no, tapa
   `/salud` y `/preguntar`.
3. Construye la ruta a `apps/web` a partir de `__file__` para que funcione desde
   cualquier directorio.

## Fuera de alcance

- Configurar CORS.

## Criterios de aceptación

- [ ] `http://localhost:8000/` muestra la página con estilos.
- [ ] `/salud`, `/preguntar` y `/docs` siguen funcionando.

## Cómo verificar

```bash
curl -s localhost:8000/ | head -5
curl -s localhost:8000/salud
```

## Entregables

- `apps/api/main.py`

## Para aprender

Archivos estáticos, qué es el origen de una página y qué es CORS.
