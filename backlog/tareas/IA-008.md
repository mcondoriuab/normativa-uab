# IA-008: Búsqueda vectorial: indexar en Supabase y buscar con pgvector

## Contexto

Para buscar por significado hay que calcular **una vez** el embedding de cada
fragmento y guardarlo. Lo guardamos en Supabase (pgvector) para que la API
desplegada en Render lo encuentre (su disco se borra en cada reinicio). Los
embeddings se piden a la API del modelo elegido en INV-009.

Después, buscar es calcular el embedding de la pregunta y pedirle a Postgres
los fragmentos más cercanos con el operador `<=>` (distancia coseno): una
consulta SQL que todo el equipo puede leer.

Esta tarea junta las antiguas IA-008 (indexar embeddings) e IA-009 (búsqueda
vectorial).

## Objetivo

Añadir la columna `embedding` a la tabla `fragmentos`, crear
`python -m ia.indexar` para guardar fragmentos y embeddings en la base, y crear
`ia/vectorial.py` con `buscar_vectorial(pregunta, k=5)`.

## Entradas

- `data/fragmentos.json` (IA-002)
- El ADR del modelo de embeddings (INV-009): modelo, dimensión y cómo se indica
  documento o pregunta
- `db/migraciones/001_inicial.sql`, `ia/db.py` (BE-008)
- `docs/ARQUITECTURA.md`, secciones *Base de datos* y *Resultado de búsqueda*
- Tu `.env` con `DATABASE_URL` y `EMBEDDINGS_API_KEY` (te los pasa el docente)

## Pasos

### Parte 1: la columna `embedding`

1. Escribe `db/migraciones/002_embeddings.sql`:

   ```sql
   create extension if not exists vector;
   alter table fragmentos add column embedding vector(N);
   ```

   Cambia `N` por la dimensión del ADR (por ejemplo, `1024`).
2. Pide al docente que la aplique en Supabase y anota la fecha en
   `db/README.md`.

### Parte 2: `ia/embeddings.py`

3. Añade el SDK del proveedor elegido a `requirements.txt` (por ejemplo,
   `voyageai`).
4. Escribe dos funciones que lean la clave de `EMBEDDINGS_API_KEY`:

   ```python
   def codificar_documentos(textos: list[str]) -> list[list[float]]:
   def codificar_pregunta(texto: str) -> list[float]:
   ```

   Usa el tipo **documento** en la primera y **pregunta** en la segunda, como
   diga el ADR (en Voyage, `input_type="document"` e `input_type="query"`).
5. En `codificar_documentos`, pide los embeddings **por lotes de 50**. Si la API
   devuelve un error de límite de velocidad, espera 20 segundos
   (`time.sleep(20)`) y reintenta ese lote, como máximo 3 veces.

### Parte 3: `ia/indexar.py`

6. Lee `data/fragmentos.json`, calcula los embeddings de todos los `texto` con
   `codificar_documentos` y guarda cada fragmento con su embedding usando una
   función nueva de `ia/db.py`, `guardar_embeddings(fragmentos, embeddings)`,
   con `insert ... on conflict (id) do update` para poder repetirlo sin
   duplicar.
7. Pasa el vector a Postgres como texto con el formato `'[0.1,0.2,...]'` y
   conviértelo en el SQL con `%s::vector`.
8. Imprime cuántos fragmentos se guardaron y cuánto tardó.

### Parte 4: `ia/vectorial.py`

9. Escribe `buscar_vectorial(pregunta: str, k: int = 5) -> list[dict]`:
   - `vector = codificar_pregunta(pregunta)`.
   - Consulta con parámetros (nunca concatenando texto en el SQL):

     ```sql
     select id, documento, articulo, pagina, texto,
            1 - (embedding <=> %(v)s::vector) as puntaje
     from fragmentos
     order by embedding <=> %(v)s::vector
     limit %(k)s
     ```

   - Convierte cada fila a
     `{"id": ..., "puntaje": ..., "fragmento": {"id", "documento", "articulo", "pagina", "texto"}}`.

## Fuera de alcance

- Índices aproximados (HNSW, IVFFlat): con unos miles de filas no hacen falta.
- Combinar con BM25 (IA-007).

## Criterios de aceptación

- [ ] La migración 002 está aplicada y registrada en `db/README.md`.
- [ ] `select count(*) from fragmentos where embedding is not null` es igual al
      número de fragmentos del JSON.
- [ ] Ejecutar `python -m ia.indexar` dos veces no duplica filas.
- [ ] La dimensión coincide con el ADR.
- [ ] `buscar_vectorial` devuelve `k` resultados ordenados de mayor a menor
      puntaje, con puntajes entre -1 y 1.
- [ ] Ninguna consulta usa *f-strings* ni `+` para construir SQL.
- [ ] Ninguna clave aparece en el código.
- [ ] Con una pregunta `coloquial` del golden set, el artículo esperado sale en
      el top-5 (si no, anótalo en *Notas de cierre*: es un dato útil para
      IA-012).

## Cómo verificar

```bash
python -m ia.indexar
python -m ia.indexar          # segunda vez: mismo número de filas
python -c "
from ia.db import conectar
with conectar() as c:
    print(c.execute('select count(*), count(embedding) from fragmentos').fetchone())
"
python -c "
from ia.vectorial import buscar_vectorial
for r in buscar_vectorial('<pregunta coloquial del golden set>'):
    print(round(r['puntaje'], 3), r['id'])
"
```
