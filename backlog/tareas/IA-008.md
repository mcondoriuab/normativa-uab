# IA-008: Indexar embeddings en Supabase

## Contexto

Para buscar por significado hay que calcular una vez el embedding de cada
fragmento y guardarlo. Lo guardamos en Supabase (pgvector) para que la API
desplegada en Render lo encuentre (su disco se borra en cada reinicio). Los
embeddings se piden a la API del modelo elegido en INV-009.

## Objetivo

Añadir la columna `embedding` a la tabla `fragmentos` y crear
`python -m ia.indexar`, que lee `data/fragmentos.json`, calcula los embeddings
por API y guarda fragmentos y embeddings en la base.

## Entradas

- `data/fragmentos.json`
- ADR del modelo de embeddings (INV-009): modelo, dimensión, documento/pregunta
- `db/migraciones/001_inicial.sql`, `ia/db.py` (BE-008)
- `docs/ARQUITECTURA.md` (sección *Base de datos*)

## Pasos sugeridos

1. Escribe `db/migraciones/002_embeddings.sql`:
   `create extension if not exists vector;` y
   `alter table fragmentos add column embedding vector(N);` con la `N` del ADR.
   Pide al docente que la aplique y anótalo en `db/README.md`.
2. Crea `ia/embeddings.py` con dos funciones:
   `codificar_documentos(textos: list[str]) -> list[list[float]]` y
   `codificar_pregunta(texto: str) -> list[float]`. Lee la clave de
   `EMBEDDINGS_API_KEY`. Usa el tipo documento o pregunta según el ADR.
   Añade el SDK del proveedor a `requirements.txt`.
3. Pide los embeddings **por lotes** (por ejemplo, de 50 en 50) y, si la API
   devuelve un error de límite de velocidad, espera y reintenta ese lote.
4. Crea `ia/indexar.py`: lee el JSON, calcula los embeddings y guarda cada
   fragmento con su embedding usando `ia/db.py`
   (`insert ... on conflict (id) do update`, para poder repetirlo sin duplicar).
5. Imprime cuántos fragmentos se guardaron y cuánto tardó.

## Fuera de alcance

- Buscar (IA-009).

## Criterios de aceptación

- [ ] `select count(*) from fragmentos where embedding is not null` es igual al
      número de fragmentos del JSON.
- [ ] Ejecutarlo dos veces no duplica filas.
- [ ] La dimensión coincide con el ADR.
- [ ] Ninguna clave aparece en el código.

## Cómo verificar

```bash
python -m ia.indexar
python -c "
from ia.db import conectar
with conectar() as c:
    print(c.execute('select count(*), count(embedding) from fragmentos').fetchone())
"
```
