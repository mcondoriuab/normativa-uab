# IA-012: Script de recall@5

## Contexto

`recall@5` responde a: ¿el artículo correcto está entre los 5 recuperados? Es el
techo del sistema: si el artículo no se recupera, ningún prompt lo arregla. Se
mide automáticamente con el golden set.

## Objetivo

Crear `eval/recall.py` para que `python -m eval.recall` imprima el recall@5 de
cada modo de búsqueda, global y por tipo de pregunta.

## Entradas

- `eval/preguntas.jsonl`
- `ia/hibrida.py` (`buscar`)
- `docs/EVALUACION.md`

## Pasos sugeridos

1. Carga el golden set y quédate con las preguntas `en_corpus: true`.
2. Para cada modo y cada pregunta, llama a `buscar(pregunta, modo=modo, k=5)` y
   mira si `id_esperado` está entre los `id` devueltos.
3. Imprime una tabla: modo × (global, literal, coloquial, multi-articulo), con
   aciertos/total y porcentaje.
4. Con `--fallos`, imprime también cada pregunta fallada con los `id` que se
   recuperaron (lo necesita el análisis de errores).

## Fuera de alcance

- Evaluar respuestas del LLM (IA-017, IA-018).

## Criterios de aceptación

- [ ] La tabla sale para los tres modos.
- [ ] Las preguntas `fuera-de-corpus` no cuentan para el recall.
- [ ] `--fallos` lista las preguntas falladas.
- [ ] Ejecutarlo dos veces da el mismo resultado.

## Cómo verificar

```bash
python -m eval.recall
python -m eval.recall --fallos
```

## Entregables

- `eval/recall.py`

## Para aprender

Métricas de recuperación, por qué medir por tipo de pregunta y no solo la media.
