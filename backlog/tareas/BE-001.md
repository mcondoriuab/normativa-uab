# BE-001: API mínima con /salud

## Contexto

La web hablará con el motor de IA a través de una API HTTP hecha con FastAPI.
Empezamos por lo mínimo: una API que arranca y responde que está viva.

## Objetivo

Crear `apps/api/main.py` con una aplicación FastAPI que responda
`GET /salud` → `{"estado": "ok"}`.

## Entradas

- `docs/ARQUITECTURA.md` (sección *API*)
- `apps/api/README.md`

## Pasos sugeridos

1. Añade `fastapi` y `uvicorn[standard]` a `requirements.txt` e instálalos.
2. Crea `apps/api/main.py` con `app = FastAPI(title="Asistente de Normativa UAB")`
   y la ruta `/salud`.
3. Arráncala desde la raíz: `uvicorn apps.api.main:app --reload`.
4. Abre `http://localhost:8000/docs` y prueba la ruta desde ahí.

## Fuera de alcance

- La ruta `/preguntar` (BE-002).
- CORS, autenticación, logs.

## Criterios de aceptación

- [x] `curl localhost:8000/salud` devuelve exactamente `{"estado":"ok"}`.
- [x] `/docs` muestra la documentación automática.
- [x] `requirements.txt` incluye las dos dependencias nuevas.

## Cómo verificar

```bash
uvicorn apps.api.main:app --reload &
curl -s localhost:8000/salud
```

## Entregables

- `apps/api/main.py`
- `requirements.txt`

## Para aprender

Qué es una API HTTP, qué son GET/POST, qué es JSON, qué hace uvicorn.

## Notas de cierre

**Qué aprendí:** que una API HTTP es un programa que espera peticiones y
responde. Una petición GET pide información y la respuesta va en formato JSON.
FastAPI convierte una función Python en una ruta con un decorador, y uvicorn es
el servidor que la ejecuta. También aprendí que `/salud` sirve para comprobar
que el servicio está vivo, y que FastAPI genera `/docs` automáticamente.

**Qué falló o qué costó:** el repositorio tenía un rebase a medias y 5 archivos
aparecían borrados, así que hubo que cancelar el rebase y restaurarlos antes de
empezar. Además, `main` estaba 11 commits por detrás de `origin/main`, y hubo
que actualizarlo antes de crear la rama.

**En qué usé IA:** la IA escribió `apps/api/main.py`, cambió el `startCommand`
de `render.yaml`, borró `hola.py` y limpió el estado de git. Revisé el código y
