# IA-004: Troceado de respaldo por longitud

## Contexto

Algunos documentos no tienen artículos (resoluciones, instructivos) o tienen un
formato que la regex no reconoce. En esos casos, en vez de perder el documento,
lo troceamos por longitud. Esos fragmentos no tendrán número de artículo.

## Objetivo

Añadir a `ia/trocear.py` la función
`trocear_por_longitud(paginas, documento, max_caracteres=1500)` y una función
`trocear(paginas, documento)` que use artículos cuando los haya y longitud
cuando no.

## Entradas

- `ia/trocear.py`
- `docs/ARQUITECTURA.md` (sección *Fragmento*: `articulo: null`, `id` con
  `#frag-<n>`)

## Pasos sugeridos

1. `trocear_por_longitud`: parte el texto de cada página por párrafos (`\n\n` o
   `\n`) y ve juntando párrafos hasta acercarte a `max_caracteres` sin pasarte.
   No cortes un párrafo a la mitad salvo que por sí solo supere el máximo.
2. Numera los fragmentos desde 1: `id = f"{documento}#frag-{n}"`,
   `articulo = None`.
3. `trocear`: llama a `trocear_por_articulos`; si devuelve menos de 3
   fragmentos, usa `trocear_por_longitud`.

## Fuera de alcance

- Solapamiento entre fragmentos, troceado semántico.

## Criterios de aceptación

- [ ] Ningún fragmento por longitud supera `max_caracteres` (salvo un párrafo
      suelto más largo).
- [ ] Un documento con artículos sigue troceándose por artículos.
- [ ] Un documento sin artículos produce fragmentos `#frag-1`, `#frag-2`…

## Cómo verificar

```bash
python -c "
from ia.trocear import trocear
f = trocear(['Primer párrafo.\n\nSegundo párrafo.'] * 50, 'prueba')
print(len(f), f[0]['id'], f[0]['articulo'], max(len(x['texto']) for x in f))
"
```

## Entregables

- `ia/trocear.py`

## Para aprender

Tamaño de fragmento: demasiado grande diluye, demasiado pequeño pierde contexto.
