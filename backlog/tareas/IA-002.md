# IA-002: Extraer texto de un PDF por página

## Contexto

Primer paso de la ingesta: pasar de PDF a texto. Lo hacemos **por página**
porque cada cita debe decir en qué página está el artículo.

## Objetivo

Crear `ia/extraer.py` con la función
`extraer_paginas(ruta_pdf: str) -> list[str]`, que devuelve el texto de cada
página (índice 0 = página 1).

## Entradas

- PDFs en `corpus/ingenieria-sistemas/`
- `investigacion/INV-006-estructura-pdf.md` si ya existe (rarezas conocidas)

## Pasos sugeridos

1. Añade `pypdf` a `requirements.txt` e instálalo.
2. Abre el PDF con `pypdf.PdfReader` y recorre `reader.pages` llamando a
   `extract_text()`.
3. Si una página devuelve `None`, guarda `""`.
4. Añade un bloque `if __name__ == "__main__":` que reciba la ruta de un PDF por
   argumento e imprima el número de páginas y los primeros 500 caracteres de la
   página 1.

## Fuera de alcance

- Limpiar el texto, detectar artículos (IA-003) u OCR.
- Procesar carpetas enteras (IA-005).

## Criterios de aceptación

- [ ] `extraer_paginas` devuelve tantas cadenas como páginas tiene el PDF.
- [ ] Funciona con todos los PDF con texto del corpus sin lanzar excepciones.
- [ ] Con un PDF escaneado devuelve cadenas vacías y no falla.

## Cómo verificar

```bash
python -m ia.extraer corpus/ingenieria-sistemas/<un-pdf>.pdf
python -c "from ia.extraer import extraer_paginas; print(len(extraer_paginas('corpus/ingenieria-sistemas/<un-pdf>.pdf')))"
```

## Entregables

- `ia/extraer.py`
- `requirements.txt`

## Para aprender

Cómo guarda el texto un PDF y por qué a veces sale desordenado o vacío.
