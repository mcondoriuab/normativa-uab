# INV-010: Comparar proveedores de LLM

## Contexto

El presupuesto para el modelo de lenguaje **no está decidido**. Hay opciones de
pago (Anthropic, OpenAI…), niveles gratuitos con límites y modelos locales
(Ollama) que no cuestan dinero pero exigen buena máquina. La arquitectura aísla
esta decisión en `ia/llm.py`, pero hay que elegir con qué empezar.

## Objetivo

Comparar al menos 3 opciones y recomendar una para el MVP en un ADR.

## Entradas

- `investigacion/INV-001-que-es-un-llm.md`
- `docs/ARQUITECTURA.md` (principio 3: modelo intercambiable)
- `docs/ETICA.md` (privacidad de las preguntas)

## Pasos sugeridos

1. Incluye al menos: una API de pago, un nivel gratuito y un modelo local vía
   Ollama. Consulta **precios y límites en la web oficial de cada proveedor**,
   con fecha de consulta: cambian a menudo.
2. Estima el coste mensual: supón 50 preguntas al día, unos 3.000 tokens de
   entrada (prompt + 5 fragmentos) y 300 de salida por pregunta.
3. Para el modelo local: requisitos de RAM y velocidad real en una máquina del
   equipo (prueba con `ollama run` y una pregunta con 5 fragmentos pegados).
4. Revisa qué hace cada proveedor con los datos enviados (retención,
   entrenamiento).
5. Prueba las 3 con la misma pregunta y los mismos 5 fragmentos, y compara la
   calidad de la respuesta.

## Fuera de alcance

- Escribir `ia/llm.py` (IA-014).

## Criterios de aceptación

- [ ] Tabla: proveedor, modelo, coste estimado al mes, límites, privacidad,
      calidad observada, velocidad.
- [ ] Todas las cifras de precio con enlace y fecha de consulta.
- [ ] ADR con la opción para el MVP y cuál es el plan B.

## Cómo verificar

El docente revisa el ADR, porque condiciona el presupuesto.
