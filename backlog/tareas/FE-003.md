# FE-003: Enviar la pregunta y mostrar la respuesta

## Contexto

La página ya existe y la API la sirve con un `/preguntar` simulado. Falta que el
formulario envíe la pregunta de verdad y muestre lo que responde la API.

## Objetivo

Crear `apps/web/app.js` para que al enviar el formulario se llame a
`POST /preguntar` y se pinten la respuesta y la lista de citas.

## Entradas

- `apps/web/index.html`
- `docs/ARQUITECTURA.md` (sección *API*)
- La API en marcha: `uvicorn apps.api.main:app --reload`

## Pasos sugeridos

1. Escucha el evento `submit` del formulario y llama a `event.preventDefault()`.
2. Usa `fetch('/preguntar', {method: 'POST', headers: {'Content-Type':
   'application/json'}, body: JSON.stringify({pregunta})})`, con `async/await`.
3. Quita del HTML el contenido de ejemplo fijo y genera la respuesta y las
   citas con `document.createElement` y `textContent`.
4. **Nunca uses `innerHTML` con texto que viene de la API**: lo escribió un
   modelo y podría contener HTML.

## Fuera de alcance

- Citas desplegables (FE-004); estados de carga, error y rechazo (FE-005).

## Criterios de aceptación

- [ ] Al preguntar, aparece la respuesta del mock y sus 2 citas.
- [ ] Una segunda pregunta reemplaza la respuesta anterior en vez de añadirse.
- [ ] `grep innerHTML apps/web/app.js` no encuentra nada.
- [ ] Sin librerías externas.

## Cómo verificar

Abrir `http://localhost:8000/`, preguntar dos veces y revisar la consola del
navegador (sin errores).

## Entregables

- `apps/web/app.js`
- `apps/web/index.html`

## Para aprender

`fetch`, promesas y `async/await`, DOM, XSS y por qué `textContent`.
