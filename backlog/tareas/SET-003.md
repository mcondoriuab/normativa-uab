# SET-001: Guía de entorno para Windows

## Contexto

Todo el motor de IA y la API se escriben en Python. Para que el código funcione
igual en todas las máquinas, cada persona trabaja en un **entorno virtual**
(`.venv`) con las mismas dependencias, listadas en `requirements.txt`.

## Objetivo

Preparar el entorno en **Windows** y dejar escrita en `docs/ENTORNO.md` una
guía que otra persona pueda seguir sin ayuda. (La guía de macOS y Linux es
SET-001.)

## Entradas

- `README.md`, `CONTRIBUTING.md`, `.gitignore`

## Pasos sugeridos

1. Instala Python 3.11 o superior desde python.org (marca **Add python.exe to
   PATH**) y Git for Windows. Comprueba en PowerShell con `python --version` y
   `git --version`.
2. Clona el repositorio.
3. Desde la raíz, crea y activa el entorno:
   `python -m venv .venv` y `.venv\Scripts\Activate.ps1`. Si PowerShell
   bloquea el script, documenta cómo lo resolviste
   (`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`).
4. Si `requirements.txt` no existe todavía, créalo con una sola línea de
   comentario: `# Dependencias del proyecto; cada tarea añade las suyas`.
5. `pip install -r requirements.txt`.
6. Copia `.env.ejemplo` a `.env`. Los valores te los pasará el docente cuando
   una tarea los necesite; `.env` nunca se sube a git.
7. Escribe en `docs/ENTORNO.md` la sección **Windows** con los pasos exactos
   que seguiste y los problemas que encontraste. Si el archivo no existe,
   créalo con dos secciones: `## macOS y Linux` (la rellena SET-001) y
   `## Windows`.
8. Pide a un compañero con Windows que siga tu guía desde cero y corrige lo que
   no le funcione.

## Fuera de alcance

- Instalar librerías de IA (sentence-transformers, etc.): las añade cada tarea
  cuando las necesita.
- Configurar editores o extensiones.
- WSL: si lo usas, sigue la guía de macOS y Linux.

## Criterios de aceptación

- [ ] `python --version` dentro del entorno muestra 3.11 o superior.
- [ ] `requirements.txt` existe en la raíz.
- [ ] La sección *Windows* de `docs/ENTORNO.md` explica paso a paso cómo
      preparar el entorno.
- [ ] Otra persona siguió la guía sin ayuda (anotado en *Notas de cierre*).
- [ ] `.venv/` y `.env` no aparecen en `git status` (los ignora `.gitignore`).

## Cómo verificar

```bash
.venv\Scripts\Activate.ps1
python --version
pip install -r requirements.txt
git status          # ni .venv ni .env deben aparecer
```

## Entregables

- `requirements.txt` (si no existía)
- `docs/ENTORNO.md`

## Para aprender

- Qué es un entorno virtual y por qué no se instala todo "global".
- Qué hace `pip` y qué es `requirements.txt`.
