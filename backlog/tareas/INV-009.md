# INV-009: Elegir el modelo de embeddings

## Contexto

El modelo de embeddings determina la calidad de la búsqueda por significado.
En producción, la API corre en Render con 512 MB de RAM, donde **no cabe un
modelo local**: los embeddings se piden a una API externa (ADR-002). El modelo
debe funcionar bien en español y tener un uso gratuito suficiente. Cambiarlo
después obliga a reindexar todo, así que conviene elegir con datos.

## Objetivo

Comparar al menos 2 modelos por API y el modelo local de INV-008 como referencia,
con nuestros fragmentos y nuestro golden set, y registrar la elección en un ADR.

## Entradas

- `data/fragmentos.json`, `eval/preguntas.jsonl`
- `investigacion/INV-008-embeddings.md`
- `historial/decisiones/ADR-002-despliegue-render-supabase.md`

## Pasos sugeridos

1. Candidatos por API: dos modelos de Voyage AI (por ejemplo, uno de la familia
   `voyage-4` y `voyage-multilingual-2`) y, si quieres, uno de otro proveedor
   con uso gratuito. Referencia local: el modelo que usaste en INV-008.
   Verifica en la documentación oficial los modelos, precios y cuotas gratuitas
   actuales, y anota la fecha de consulta.
2. Lee la documentación de cada modelo: dimensión del vector, idiomas y si
   distingue entre **documento** y **pregunta** (Voyage usa el parámetro
   `input_type`; algunos modelos locales usan prefijos). Si no se indica, la
   calidad baja sin ningún error visible.
3. Pide al docente la clave de prueba y guárdala en tu `.env` (nunca en el código).
4. En un script: codifica los fragmentos y las preguntas `en_corpus` del golden
   set y cuenta en cuántas el `id_esperado` queda en el top-5 por coseno (con
   NumPy basta para este experimento).
5. Anota tokens consumidos, tiempo total y límites de velocidad que encuentres.
6. Tabla comparativa + ADR con la elección.

## Fuera de alcance

- El código definitivo del índice (IA-008) o del esquema (IA-008, BE-008).

## Criterios de aceptación

- [ ] Tabla con: modelo, proveedor, dimensión, documento/pregunta sí/no, aciertos
      top-5, tokens usados, tiempo, cuota gratuita.
- [ ] ADR con el nombre exacto del modelo, su **dimensión** y cómo se indica
      documento o pregunta.
- [ ] El script de prueba está en `investigacion/` y no contiene claves.

## Cómo verificar

git grep -n -i "api_key *= *['\"]" investigacion/     # no debe mostrar nada

datos propios y no con rankings genéricos.
