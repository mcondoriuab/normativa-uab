# IA-011: Comando buscar

## Contexto

Antes de meter un LLM hay que poder comprobar a ojo qué recupera la búsqueda.
Un comando de consola permite hacerlo en segundos y en demos.

## Objetivo

Crear `ia/buscar.py` para que `python -m ia.buscar "pregunta" --modo hibrida`
imprima los 5 mejores fragmentos.

## Entradas

- `ia/hibrida.py`

## Pasos sugeridos

1. `argparse`: argumento posicional `pregunta`, opción `--modo` (bm25 |
   vectorial | hibrida, por defecto hibrida) y `--k` (por defecto 5).
2. Para cada resultado imprime: posición, puntaje con 3 decimales, `id`,
   página y los primeros 200 caracteres del texto.

## Fuera de alcance

- Generar respuestas (IA-016).

## Criterios de aceptación

- [ ] Funciona con los tres modos.
- [ ] `--help` explica las opciones.

## Cómo verificar

```bash
python -m ia.buscar "cuántas faltas puedo tener" --modo bm25
python -m ia.buscar "me pueden echar por faltar mucho"
```

## Entregables

- `ia/buscar.py`

## Para aprender

Interfaces de línea de comandos con `argparse`.
