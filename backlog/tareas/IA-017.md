# IA-017: Umbral de rechazo calibrado

## Contexto

Pedirle al modelo que rechace no basta: si le pasamos fragmentos poco
relevantes, a veces igual "responde". Una defensa más: si el mejor fragmento se
parece poco a la pregunta, rechazar **sin llamar al modelo**, lo que además
ahorra dinero. El umbral no se inventa: se calibra con el golden set.

## Objetivo

Elegir con datos un `UMBRAL_RELEVANCIA` sobre el puntaje vectorial del mejor
fragmento y aplicarlo en `responder()`.

## Entradas

- `ia/responder.py`, `ia/hibrida.py` (`puntaje_vectorial`)
- `eval/preguntas.jsonl`

## Pasos sugeridos

1. Crea `eval/umbral.py`: para cada pregunta del golden set, calcula el
   `puntaje_vectorial` del mejor resultado y guárdalo junto a `en_corpus`.
2. Imprime los puntajes de las preguntas en corpus y los de fuera de corpus
   ordenados, y para varios umbrales candidatos cuántas de cada grupo se
   rechazarían.
3. Elige el umbral que rechaza todas (o casi todas) las de fuera de corpus
   rechazando el mínimo de las legítimas. Justifica el compromiso.
4. En `responder()`, si el mejor puntaje es menor que `UMBRAL_RELEVANCIA`,
   devuelve el rechazo sin llamar a `generar`.
5. Registra la calibración en `historial/evaluaciones/`.

## Fuera de alcance

- Clasificadores de intención o de temas.

## Criterios de aceptación

- [ ] `eval/umbral.py` imprime la tabla de umbrales candidatos.
- [ ] `UMBRAL_RELEVANCIA` está en `ia/responder.py` con un comentario que
      enlaza la evaluación.
- [ ] La evaluación incluye la tabla y el porqué del valor elegido.
- [ ] Con el umbral, las preguntas fuera de corpus del golden set se rechazan
      sin llamar al LLM.

## Cómo verificar

```bash
python -m eval.umbral
python -m ia.responder "cuál es la mejor universidad del país"
```

## Entregables

- `eval/umbral.py`
- `ia/responder.py`
- `historial/evaluaciones/AAAA-MM-DD-umbral.md`
