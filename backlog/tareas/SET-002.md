# SET-002: Primer pull request: añadirse al equipo

## Contexto

Todo cambio en este repositorio entra por un *pull request* (PR) revisado por
otra persona. Esta tarea es para practicar el flujo completo con un cambio
mínimo antes de tocar código. **La hace cada integrante**, una vez.

## Objetivo

Añadir una fila con tus datos a `EQUIPO.md` mediante tu propia rama y PR.

## Entradas

- `CONTRIBUTING.md` (el flujo completo)
- `docs/GIT.md` (si ya existe, SET-004)
- `EQUIPO.md`

## Pasos sugeridos

1. `git switch main && git pull`
2. `git switch -c SET-002-<tu-nombre>`
3. Añade tu fila a `EQUIPO.md` (nombre, rol `estudiante`, semestre, usuario de
   GitHub, fecha de hoy).
4. `git add EQUIPO.md && git commit -m "SET-002: añadir <tu nombre> al equipo"`
5. `git push -u origin SET-002-<tu-nombre>` y abre el PR en GitHub.
6. Pide a un compañero que lo revise y lo apruebe.
7. Esta tarea es **una sola para todo el equipo**: en tu PR **no** escribas
   `Closes #…` (cerraría el issue para todos). Cuando se mezcle tu PR, marca tu
   casilla en la lista del issue. El docente lo cierra cuando todos hayan hecho
   la suya.

## Fuera de alcance

- Cambiar cualquier otro archivo.

## Criterios de aceptación

- [ ] Tu fila está en `EQUIPO.md` en `main`.
- [ ] El commit empieza por `SET-002:`.
- [ ] El PR fue aprobado por otra persona antes del merge.

## Cómo verificar

```bash
git switch main && git pull
git log --oneline -5      # tu commit aparece
cat EQUIPO.md             # tu fila aparece
```

## Entregables

- `EQUIPO.md`

## Para aprender

- Rama, commit, push, pull request, revisión y merge.
- Por qué nadie sube directo a `main`.
