## Cómo ejecutar cuando haya cuota

```bash
python -m eval.umbral
```

El script muestra:
1. Los puntajes vectoriales de cada pregunta, separados por dentro/fuera del corpus.
2. Una tabla de umbrales candidatos con el número de preguntas rechazadas en
   cada grupo.

## Criterio para elegir el umbral

Se busca rechazar TODAS (o casi todas) las preguntas fuera del corpus
rechazando el MÍNIMO de las dentro del corpus. El umbral óptimo es el que
primero alcanza `acierta_fuera = N/N` (donde N es el total de preguntas fuera
del corpus) con la menor cantidad de rechazos en el corpus.
