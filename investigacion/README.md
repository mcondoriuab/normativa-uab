# investigacion/

Informes de las tareas de investigación (`INV-*`). Un archivo por tarea:
`INV-001-que-es-un-llm.md`.

## Formato

```markdown
# INV-00X: título

**Autor(es):** · **Fecha:** AAAA-MM-DD

## Pregunta
Qué queríamos saber.

## Lo que encontramos
En nuestras palabras. Ejemplos concretos.

## Evidencia
Fuentes consultadas (enlace + qué dice) y experimentos hechos.

## Conclusión para el proyecto
Qué implica para lo que construimos. Si lleva a una decisión, enlazar el ADR.

## Preguntas abiertas
```

Reglas: citar fuentes primarias (documentación oficial, artículos) antes que
blogs; distinguir lo que **dice la fuente** de lo que **concluimos nosotros**; y
si se usó IA para investigar, decirlo y verificar lo que afirmó.
